Multica에는 로그인이 없습니다. 서버 하나가 로컬 사용자 한 명에게 응답하며, 모든 요청을 그 사용자의 요청으로 취급합니다. Web, Desktop, CLI, 데몬에는 자격 증명이 필요하지 않습니다. 이 문서에서 설명하는 자격 증명은 남은 하나, 즉 에이전트가 태스크를 실행하는 동안 사용하는 임시 토큰입니다.

## 에이전트 실행용 임시 토큰

데몬이 실행을 가져가면 서버가 해당 실행을 위해 `mat_`로 시작하는 임시 토큰을 만듭니다. 현재 사용자, 워크스페이스, 에이전트, 실행에 연결되고 최대 24시간 동안 유효하며 실행이 끝나면 정리됩니다.

데몬은 이 임시 토큰을 AI 코딩 도구에 주입합니다. 따라서 에이전트가 보낸 요청은 에이전트의 동작으로 기록되며 사용자나 owner만 수행할 수 있는 민감한 작업을 이 토큰으로 호출할 수도 없습니다.

이 토큰은 서버가 자동으로 만들며 사용자가 저장하거나 관리할 필요가 없습니다.
